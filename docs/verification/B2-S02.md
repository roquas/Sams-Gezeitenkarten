# B2-S02: deterministischer 20-Karten-Probelauf

Dieser Entwicklungsbestand enthält **alle 96 gespeicherten Kandidaten** aus
20 unterschiedlichen Karten, 48 Starts und 48 Zielrouten. Keine qualitative
Vorauswahl, neue Qualitätsmetrik, geänderte Suchgewichtung oder Veröffentlichung.

## Hinweise in zwei getrennten Dimensionen

[Vollständige Tabellen und Kreuztabelle](B2-S02/clue-report.md) ·
[Maschinenlesbarer Bericht mit Einzelvorkommen](B2-S02/clue-report.json).

283 von 340 Hinweisen verwenden logisch `countDistanceToPlace` (83,24 %).
Diese 283 Vorkommen verteilen sich auf 186 `countDistanceToPlace`,
56 `CountDistanceNever`, 27 `HasDistanceAt` und 14 `NotDistanceAt`.

`distanceBetweenHours` (15), `direction` (8), `turn` (7) und `position` (1).

Alle Häufigkeiten zählen gespeicherte Hinweise je Kandidat, ohne Deduplikation
zwischen Kandidaten. Poolhäufigkeiten und verworfene Suchergänzungen bleiben
getrennt. Die Form ist deterministisch abgeleitet und wird nicht erst beim Export
gewählt. Die gespeicherte Kandidateneigenschaft `cluePresentationForms` enthält nur
verschiedene Formen, keine Vorkommenszahlen. Alle Rand- und Gesamtsummen der
Kreuztabelle stimmen; es gibt im verwendeten Vertrag keine mehrdeutige Formauswahl.

## Eingefrorene Übergabe, Identitäten und Spielbarkeit

- `B2-S02/source-batch/`: alle vier unveränderten Batchdateien.
- `B2-S02/b1/`: alle drei unveränderten B1-Dateien.
- `B2-S02/run/`: vier deterministische B2-Dateien und getrennte beobachtete Laufzeiten.
- `../../scripts/config/b2-playtest-s02.json`: einmalige Zuordnung aller 96 Namen
  zu Experiment, Zielversuch, Karten-/Instanz-/Variantenfingerprints,
  Wirkungsschlüssel und Inhaltshash aus Definition samt Motivbelegung.

Ein Name wie `B2-S02-M000-A1-R00-V01` bindet den ursprünglichen akzeptierten
Kartenindex 000, Start A1, Routenindex 0 und einmal vergebene Variante 01. Die
ursprünglichen Generatorversuchsindizes bleiben zusätzlich in den Quellzeilen
erhalten. Exportreihenfolge oder eine spätere Auswahl vergeben keine Namen neu.
Die Registry enthält sämtliche erfolgreichen Kandidaten; es gibt keinen
Qualitätsfilter oder automatischen Nachschub für verworfene Suchschritte.

`npm run dev:b2:s02` exportiert nach `.dev/b2-s02/` und startet den lokalen Server.
Öffnen: [S02](http://localhost:8000/?dev=b2&stock=S02).
S01 bleibt Standard für `npm run dev:b2`, Export/Inspektion ohne Bestandsangabe und
`?dev=b2`. Exporte sind bytegleich reproduzierbar und enthalten weder Zielroute
noch private Suchdiagnostik; der vorhandene Compiler prüft die Lösung erneut.
Der reguläre Paketbuild verwendet weiterhin ausschließlich das normale Manifest.

## Vollständige Reproduktion

Node **v24.19.0**, Git und vollständige Repositoryhistorie sind erforderlich.
Die Zielverzeichnisse dürfen noch nicht existieren. Der automatisierte Test führt
die bestehenden CLIs im originalen, sauberen Programmcheckout aus und vergleicht
alle elf deterministischen Dateien byteweise. Zusätzlich prüft er Karten-Replay
für die ursprünglichen Indizes 0 und 19. Er ist ein eigener CI-Job mit der exakten
Node-Version; die reguläre Node-22-Unitsuite muss keine andere Laufzeit vortäuschen.

```sh
npm run test:b2:s02:reproduction
```

Manuell mit denselben bestehenden Befehlen:

```sh
git worktree add --detach /tmp/gk-s02-reproduce-program d30c6683e8ba74e72ea1e9aae6e3aaa99295f207
node /tmp/gk-s02-reproduce-program/scripts/generate-map-batch.mjs run \
  --release gk-catalog-release-v1-sha256-f9dbeb5e6be3664adcef72c1624615e7a016681cd4024ad0442fd54ec825497e \
  --background sea-blue-01 --target-count 20 --max-attempts 40 \
  --seed-start 0 --assignment-seed-start 0 --out /tmp/gk-s02-reproduce-batch
node /tmp/gk-s02-reproduce-program/scripts/run-route-experiment.mjs \
  --batch /tmp/gk-s02-reproduce-batch --accepted-indices all \
  --max-nodes-per-start 100000 --out /tmp/gk-s02-reproduce-b1
node /tmp/gk-s02-reproduce-program/scripts/run-puzzle-experiment.mjs \
  --b1 /tmp/gk-s02-reproduce-b1 --batch /tmp/gk-s02-reproduce-batch \
  --out /tmp/gk-s02-reproduce-b2 --seed 42 --route-indices 0 \
  --max-nodes-per-start 100000 --max-clue-parameters 100000 \
  --max-restarts 2 --max-solver-checks 2000 \
  --max-match-evaluations 5000000 --max-route-filter-evaluations 20000000
node scripts/verify-puzzle-experiment.mjs /tmp/gk-s02-reproduce-b2/candidates.jsonl
```

Die vier Dateihashes des Quellbatches stehen im B1-Manifest; die B1-Dateihashes und
erneut geprüften Quellbatchhashes stehen im B2-Manifest. Der Reproduktionstest
vergleicht darüber hinaus direkt alle vier Batch-, drei B1- und vier B2-Dateien.
`timings.json` enthält Hardware-/Lastbeobachtungen und gehört nicht zur Bytegleichheit.

```sh
npm run test:unit

```

Die neuen Verträge prüfen alle S02-Exporte mit dem echten Loader, alle Kandidaten
mit dem bestehenden unabhängigen Solver und die neuen Tabellen gegen feste
Erwartungen und die ursprüngliche Zusammenfassung. Die S01-Exportreferenz wurde
einmalig mit dem unveränderten Generierungsbasiscommit gewonnen. Zusätzlich werden
historische S01-Dateien und archivierte Releases byteweise gegen diesen Commit
geprüft. Generator-/Solver-/Hinweismodule sind im PR-Diff unverändert; die
bestehenden funktionalen Regressionen bleiben erhalten. Browserprüfungen decken beide Bestände,
Variantenwechsel, getrennte Spielstände, direkte Links, alle neun tatsächlich
vorkommenden Darstellungskennungen, Lösungskontrolle und Fehlerfälle ab.

Lokale Abnahme am 03.11.2026:

- Vollständige Unit-Suite: **289 bestanden**, keine übersprungenen Prüfungen.
- Vollständige S02-Reproduktion: alle elf fachlichen Dateien bytegleich,
  Karten-Replay 0 und 19 jeweils `matched`.
- Unabhängige Kandidatenprüfung: alle 96 S02- und erneut alle 95 S01-Kandidaten bestanden.
- S01-Standardexport: alle 96 Dateien einschließlich Manifest entsprechen exakt
  der am unveränderten Basiscommit gewonnenen Exportreferenz.
- Contenttests und reguläre Puzzlevalidierung bestanden.
- Chromium Desktop/Mobil: 26 B2-/Langtextprüfungen bestanden; die verstärkte
  Auswahlpersistenzprüfung zusätzlich auf beiden Projekten bestanden.
- WebKit Desktop/Mobil: alle 26 B2-/Langtextprüfungen bestanden.
- Paketregression: 19 Python-Tests bestanden; reguläres ZIP mit 109 Laufzeitdateien,
  ohne Entwicklungsbestände oder private Berichte, SHA-256
  `28b2a441938428bb3d9068cca209880e19636bcc9ec6c3a8b923bbb347469166`.
- Katalogarchivprüfung: zwei gültige Releases, bestehendes Archiv unverändert.

Unterprozesstests liefen wegen der bekannten `spawnSync EPERM`-Beschränkung
außerhalb der lokalen Sandbox. Für den lokalen WebKit-Lauf wurden fehlende
Bibliotheken temporär im heruntergeladenen Browserbundle bereitgestellt und die
Hostabhängigkeits-Vorprüfung übersprungen; sämtliche Browserassertionen blieben
aktiv. Die unveränderten CI-Browserjobs verwenden weiterhin die reguläre
Playwright-Installation einschließlich Systemabhängigkeiten.

Die spätere qualitative Sichtung und Auswahl ist ein eigener Auftrag. S01,
historische Fingerprints, Releases und deren Freigaben bleiben unverändert.
