# S03-v2 – lösungsfreie Spieltestübersicht

Vorbereitete experimentelle Serie mit neun Rätseln. **Für menschliche Tests erst
nach Freigabe verwenden.** Technische Prüfung ist keine menschliche Bestätigung
von Schwierigkeit, Spielspaß oder Abwechslung.

Die Kennungen sind keine Schwierigkeitsstufen. Die Reihenfolge enthält keine
Hinweise zum Lösungsweg. Die vier v1-Kandidaten werden nicht als eigene neue
menschliche Testserie verwendet; v1 bleibt ein technisches Archiv.

## Lokaler Zugang

```sh
npm run dev:b2:s03
```

Dieser Aufruf exportiert ausdrücklich **S03-V2**. Anschließend
[S03-v2 öffnen](http://localhost:8000/?dev=b2&stock=S03-V2).
Alternativ: `npm run dev:b2:s03-v2`.

Die vorhandene Oberfläche enthält Stundenmarkierungen, Undo, Lösungskontrolle,
den Mehrhex-Radar und die freigegebenen Hinweisformulierungen. Testauswahl und
Spielstände sind von anderen Beständen getrennt. Es erfolgt keine automatische
Veröffentlichung oder Umstellung des täglichen Spiels.

## Neutrales Testprotokoll

Nach Freigabe je gespieltem Rätsel die angezeigte Kennung festhalten. Freie Wahl
der Reihenfolge; keine vorgegebene Bearbeitungszeit.

- Wie angenehm oder mühsam war das Rätsel insgesamt?
- Gab es befriedigende Entdeckungen oder frustrierende Stellen?
- Waren eigene Notizen ausreichend und die Bedienelemente verständlich?
- Fühlte sich das Rätsel gegenüber zuvor gespielten Rätseln anders an?
- Wie lange wurde ungefähr gespielt, und wurde es abgeschlossen?

Detaillierte Beobachtungen zu eigenen Lösungswegen getrennt von diesem allgemeinen
Zugang festhalten, damit weitere Mitspielende unbeeinflusst bleiben. Diese
Übersicht enthält keine Lösungen, Anker, Mechanismen oder individuellen Bewertungen.
