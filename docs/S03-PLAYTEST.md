# S03 – lösungsfreie Spieltestübersicht

Dies ist eine experimentell ausgewählte Serie für menschliche Spieltests.
Die Kennungen sind keine Schwierigkeitsstufen. Die Reihenfolge enthält keine
Hinweise zum Lösungsweg. Es gibt noch keine menschliche Qualitätsbestätigung.

## Zugang

```sh
npm run dev:b2:s03
```

Anschließend [S03-Spieltest öffnen](http://localhost:8000/?dev=b2&stock=S03).
Die vorhandene Oberfläche enthält Stundenmarkierungen, Undo, Lösungskontrolle
und den Mehrhex-Radar. Die Testauswahl und Spielstände bleiben getrennt von
anderen Beständen.

Dies ist ein lokaler Entwicklungszugang. Es erfolgt keine automatische
Veröffentlichung oder Umstellung der täglichen Rätsel. Bei späterer Bereitstellung
wird aus dem dann freigegebenen Stand erneut exportiert, damit dessen freigegebene
Hinweisformulierungen verwendet werden.

## Testprotokoll

Bitte je gespieltem Rätsel die angezeigte Kennung festhalten. Freie Wahl der
Reihenfolge; keine vorgegebene Bearbeitungszeit.

- Wie angenehm oder mühsam war das Rätsel insgesamt?
- Gab es befriedigende Entdeckungen oder frustrierende Stellen?
- Waren die eigenen Notizen ausreichend und die Bedienelemente verständlich?
- Fühlte sich das Rätsel gegenüber zuvor gespielten Rätseln anders an?
- Wie lange wurde ungefähr gespielt, und wurde es abgeschlossen?

Technische Diagnosen und Lösungen gehören nicht in diese Übersicht. Detaillierte
Beobachtungen zu eigenen Lösungswegen bitte getrennt vom allgemeinen Spieltestzugang
festhalten, damit weitere Mitspielende unbeeinflusst bleiben.
